# Auragate — 3D Cabin Window Portal & Volumetric Sky Carousel

Interactive scroll-driven 3D airplane window portal and volumetric sky world showcase built with React 19, TypeScript, Three.js WebGL, and Tailwind CSS.

## Features
- **Stage 1 (Cabin Window Hero)**: Molded 3D aircraft window bezel with pull-down shade handle, acoustic dark cabin wall texture, and bottom-left/right editorial typography.
- **Stage 2 (Sky Cloud Carousel)**: Smooth scroll-driven zoom through the aircraft window aperture into a cerulean sky with drifting volumetric clouds and a 5-card 3D frosted-glass testimonial arc.
